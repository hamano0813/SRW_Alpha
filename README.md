# SRW Alpha ROM Editor — 超级机器人大战α ROM 编辑器

[![Python](https://img.shields.io/badge/Python-≥3.14-blue?logo=python&style=flat&labelColor=013243)](https://www.python.org/)
[![PySide6](https://img.shields.io/badge/PySide6-6.7+-green?logo=qt&style=flat&labelColor=013243)](https://doc.qt.io/qtforpython-6/)
[![qfluentwidgets](https://img.shields.io/badge/qfluentwidgets-1.9.2+-orange?style=flat&labelColor=013243)](https://qfluentwidgets.com/)

基于 **PySide6** 的 ROM 静态编辑器，仅为 **PS 版《超级机器人大战α》** 设计
支持编辑游戏内机体、机师、武器、文本、战场配置、敌方 AI、剧情分支等数据
目前仅支持日版，汉化版因字库原因暂不支持，游戏数据可通用

---

## 功能一览

### 已实现

- **机体数据编辑** — 属性、地形适性、特殊能力、武装参数、BGM、变形/分离、系列
- **机师数据编辑** — 能力、地形适性、技能、养成、系列
- **场景文本编辑** — 游戏关卡内文本编辑
- **镜像文件解析** — ISO 解包与重建
- **多种语言界面** — English / 简体中文 / 日本語

### 计划实现

- 场景流程编辑 — 剧情事件、敌方配置、AI
- 剧本流程编辑 — 幕前幕中幕尾流程
- 游戏参数编辑 — 改造幅度、精神消耗、芯片属性等
- 全角字符重绘 — 提供重绘游戏字库的功能

## ROM准备

1. 准备《超级机器人大战α》的日版 PS1 光盘镜像（.bin/.cue）
2. 在设置中配置读取的ROM文件路径和保存的ROM文件路径

修改所需各模块文件由编辑器自动解包至修改器的缓存目录，无需手动配置

## 操作说明

> 修改有风险，请自行备份好不同版本文件

- 概览 > 解包ROM 将ROM解包为缓存文件，放在本修改器目录下
- 概览 > 解析缓存 将缓存文件内的游戏数据解析后，开启编辑功能
- 概览 > 构建缓存 将游戏界面编辑完成的数据写入缓存文件
- 概览 > 重建ROM 将缓存文件重新按照设定的保存路径打包成ROM文件
- 机体 > 机体名称、机体数据、变形合体、换装系统、地形适应、特殊能力、换乘系统、BGM均可修改
  - 变形：由变形组号决定，同一组号的机体之间可以互相变形，以变形序号决定变形选项的顺序，最小组号1，上限未知，序号范围0-2，支持3段变形，更多变形未测试
  - 合体：有两种合体模式：
    - 核心战机模式：合体组号为0，仅需设定机体本体，核心战机侧无需设定，机体本体合体数量为1，选择核心战机为核心机体
    - 零件合体模式：由合体组号决定，每台零件均需设置，同一组号的零件可以合体，以合体序号决定顺序，最小组号1，上限未知，序号范围0-4，支持5机合体，另机体本体需要设置核心机体和合体数量
  - 换装：游戏内仅两个换装系统，分别是V2高达和修克拜因MK-III，不要随便修改
  - 地形：含类型和适应两部分，类型决定机体是否可以在对应的地图上出击，适应决定移动力和其他一些计算
  - 特殊能力：含机体可见的所有能力和不可见的能力，勾选即可，选择过多是否死机未测算
  - 换乘系：勾选后可以由同样勾选了对应系的机师进行换乘
  - BGM：选择机体战斗时切换的BGM音乐，部分BGM有多个版本或未在音乐回放内出现，为游戏隐藏音乐
- 机体 > 武器 > 武器名称、类型、攻击力、属性、命中、会心、消耗、需求，改造类型、改造追加武器、地图武器属性、地形适应均可修改
  - 类型：可切换修改格斗/射击
  - 属性：包括是否可P，是否光束兵器，是否可以被切等，诱导兵器包括bit和浮游炮，分离仅用于V高达系的BOTTOM ATTACK，突击为猜测项目，仅用于V高达的光之翼，水中武器不可对陆上攻击
  - 需求：包括气力和技能等级需求，技能等级从0-3，不支持更高等级定义
  - 改造类型：对应参数编辑（尚未实现功能）中的四套改造配置，包括攻击力提升幅度和所需金钱
  - 改造追加：可以选择本机的一个武器作为改满追加的隐藏武器，取消目标武器隐藏，只需取消此处选择即可
  - 地图武器：分三个类型，方向指定，自机中心，着弹指定，选择任意一项时，可以选择地图武器的演出，部分演出为剧情演出，没有武器使用，编辑器已限定范围，最大值不会死机
    - 方向指定：选择方向指定时，武器属性中的射程仅提供纸面显示，实际伤害范围由右侧可选择的地图武器范围决定，其中爆导索因面积自定义，仅为示例
    - 自机中心：由武器属性中远射程决定杀伤范围
    - 着弹指定：由武器属性中远射程决定起爆中心点距离，由杀伤半径框内数值决定从起爆中心点起算的杀伤范围，起爆中心点为1，最小的有意义数值为2
  - 地形适应：武器的地形适应
- 机师 > 机师名字、全名、机师数据、性格、二回行动等级、初始SP、气力组、精神指令、特殊技能、换乘系统、等级制技能、地形适应均可修改
  - 气力组：同数值机师为一个气力小组，互相靠近可以获得隐藏的气力加成
  - 精神指令：支持精神选择和习得精神的等级编辑
  - 特殊技能：为游戏中机师的不可升级的技能，其中包括部分隐藏技能，王子、王女用途不知，王牌、两次行动可直接点亮机师界面的图标，主人公标记了全部主角人物，AI标记了所有杂兵和人造BOSS，功能未知
  - 换乘系：同机体换乘系，勾选后可以换乘勾选了同样选项的机体
  - 等级制技能：可以定义机师的可升级技能，包括新人类和圣战士等，还可定义习得技能的等级
  - 地形：同前所述
- 文本 > 可以编辑战场地图内使用的所有场景文本，包含关卡胜利失败条件，地图上的疑问选择文本，和角色对话等
  - 右侧有简单的搜索过滤功能、输入十六进制序号定位功能、选择特定发言人过滤其所有发言功能
