# DC.BIN 解析/构建模块

## 概述

`DC.BIN` 是《超级机器人大战α》ROM 中的角色图鉴数据文件，
由 350 个 LZSS 压缩块组成（1 个名册 + 349 条角色详情）。

## 文件结构

```code
0x0000~0x057B  指针表（351 × uint32 LE）
0x057C~EOF     数据区（LZSS 压缩块，pack=4 对齐）
```

- `ptr[0]` 指向块 0（名册），`ptr[351]` 指向文件尾
- 数据块数 = `ptr_count - 1` = 350 个

## 块 0：角色名册

- 349 × 0x30 字节记录
- 每条记录：左对齐文本 + `00` 截断 + `CD` 补齐 + 末尾 N × `00`
- 末尾 `00` 数 == 文本中半角 ASCII 字符数（英文字母视为全角，不计入）

### 掩码规则

名册记录采用 `CD` 掩码，在定长槽内覆写：

```code
[文本字节码][00][CD CD ... CD][00 00 ... 00]
                             └─ N 个 00 ─┘
                             N = 半角 ASCII 数
```

示例：

- `リン=マオ`：`=` × 1 → 末尾 1 个 `00`
- `スレッガ-=ロウ`：`-` × 1, `=` × 1 → 末尾 2 个 `00`
- `シロ`：无半角 ASCII → 末尾 0 个 `00`

> **已知例外**：部分纯汉字名（如 `張五飛`、`兜甲児`）使用全 `00` 掩码
> 而非 `CD`，推测为不同开发团队的数据格式未统一。
> 重建时统一使用 `CD` 掩码，文件功能不受影响。

## 块 1~349：角色详情

解压后按固定偏移布局：

| 偏移  | 大小 | 字段        | 说明                        |
| ----- | ---- | ----------- | --------------------------- |
| 0x00  | 0x30 | fname       | 完整名，CD 掩码覆写         |
| 0x30  | 0x14 | pname       | 爱称，CD 掩码覆写           |
| 0x44  | 0x40 | appr        | 登场作品，CD 掩码覆写       |
| 0x84  | 0x14 | voice       | 声优，CD 掩码覆写           |
| 0x98  | 1    | flags       | 标识字节                    |
| 0x99  | 3    | —           | 固定 `00 00 00`             |
| 0x9C+ | 可变 | desc        | 描述文本，每行 1 个 0x30 槽 |

所有文本字段左对齐、`00` 截断、`CD` 补齐。
描述文本在 Python 层用 `\n` 拼接，每行以 `00 00` 作为行分隔符。

> **已知例外**：块 214（暗黒大将軍）的描述区末尾多一个全空的
> 0x30 槽（`00 00 CD CD...`），为游戏原始数据的冗余。
> 重建时不会生成此空槽，文件功能不受影响。

## Python API

### `parse(data, extra=None, trans=None) -> dict`

```python
from core.dc_bin import parse

data = parse(open("DC.BIN", "rb").read())
# {
#     "name": "dc",
#     "count": 349,
#     "roster": ["イルムガルト=カザハラ", ...],
#     "dc": [
#         {
#             "fname": "スレッガー＝ロウ",
#             "pname": "スレッガー",
#             "appr": "機動戦士ガンダム",
#             "voice": "井上真樹夫",
#             "flags": 10,       # 0x0A
#             "desc": "ホワイトベースが...\n上がる際に...",
#         }
#     ]
# }
```

### `build(data, extra=None, trans=None) -> bytearray`

```python
from core.dc_bin import build

raw = build(data)                        # 往返重建
raw = build(data, extra=HALF_TEXT_EXTRA) # 带映射重建
```

## 标识字节 (flags)

位于偏移 0x98，单字节，范围 0x02~0x1D。用于控制图鉴界面排序和头像展示，
具体位域含义待游戏内验证。

## 构建

```bash
# 项目根目录统一构建
python build_project.py

# 或手动编译
cd src/core/dc_bin
python setup.py build_ext --inplace
```

## 字节级往返一致性

除以下已知差异外，`parse → build` 可实现完整字节级往返：

| 差异项       | 原因                                | 影响         |
| ------------ | ----------------------------------- | ------------ |
| 块 0（名册） | 纯汉字记录掩码规则未实现，统一用 CD | 压缩大小略小 |
| 块 214       | 官方冗余空 cell                     | 压缩大小略小 |

其余 348 个详情块逐字节完全一致。
