# SNDATA.BIN --- 场景数据文件

## 文件格式

```code
+0x0000  UINT32 场景指针[0x200]
         - 前 0x8C 个有效，指向场景绝对偏移
         - 指针[0x8C] = 文件大小（结束标记）
         - 余下为 0x00
+0x0800  SCENARIO[0x8C] 连续排列，每块 0x4048B
```

## SCENARIO 结构 (0x4048B)

```code
+0x00  UINT32  区块数量             固定 0x10
+0x04  UINT32  指针宽度             固定 0x04
+0x08  UINT32  区块指针[0x10]       指向 0x48 后的指令偏移（单位=2B）
                                    索引 0 固定为 0(BLOCK 0)
                                    索引 1~0x0A = 区块 1~A 的起始
                                    索引 0x0B~0x0F 未使用 = 0xFFFFFFFF
+0x48  指令流 …                     连续指令，0xFF 终止
+余下  0xFF 填充
```

## 指令格式

```code
<code(1B) count(1B)>  param[0](2B) param[1](2B) …
总长 = count × 2 字节
count=1 → 无参数（仅 header 占 2B）
count≥2 → (count-1) 个 INT16 参数
参数以小端序（LE）读取，按原始 2 字节值解读。有符号/无符号的语义因具体指令和参数位置而异（例如坐标用有符号，编号用无符号）。
```

## 指令释义

各指令通过 code 字段索引，对应一个函数调用，params 为入参。
以下按类别分组说明。`Cnt` = 指令的 count 值（单位数，×2 = 字节长度），除 0xB9 外均为定长。

### 流程控制

| Code | Cnt | 格式 | 参数 | 说明 |
| ---- | --- | ---- | ---- | ---- |
| 0x00 | 2 | `BLOCK<{0}>` | 区块序号（0~0x0A） | BLOCK 区块号申明。指令流以 BLOCK(0) 开始，每关 11 个区块（0-0xA） |
| 0x01 | 1 | `STOP` | — | BLOCK 区块结束符 |
| 0x02 | 2 | `ALL ({0})` | 嵌套层级 | 检查**全部**表达式是否为真（逻辑 AND）。嵌套层级标识当前 IF 嵌套深度 |
| 0x03 | 2 | `ANY ({0})` | 嵌套层级 | 检查**任一**表达式是否为真（逻辑 OR） |
| 0x04 | 2 | `THEN ({0})` | 嵌套层级 | 检查结果为真（TRUE）时执行 |
| 0x05 | 2 | `ELSE ({0})` | 嵌套层级 | 检查结果为假（FALSE）时执行 |
| 0x06 | 2 | `END ({0})` | 嵌套层级 | 结束判断符 |
| 0x08 | 2 | `GOTO {0}` | 目标偏移（单位=2B） | 跳转到当前区块内的指定偏移（相对 0x48，以 2 字节为单位） |
| 0x09 | 2 | `RUN {0}` | 目标偏移（单位=2B） | 执行调用——跳转到偏移处执行，遇到 0x0A（BACK）后返回 |
| 0x0A | 1 | `BACK` | — | 回调符号。RUN 指令调用的子程序返回点。也用于间隔不同的受控指令区 |

## 参数类型说明

| 类型 | 说明 |
| ---- | ---- |
| 机师编号 | 小端序 INT16。0x07D0 = 主角, 0x00B1 = 甲児, 0x00B5 = あしゅら |
| 机体编号 | 小端序 INT16。0x00CF = ホバーパイルダー |
| 表情代码 | 03=通常, 02=笑容, 05=惊讶, 00=真面目? |
| 阵营 | 0000=中立, 0001=本方, 0002=友军, 0003=敌军 |
| 势力掩码 | 位掩码表示势力编号（bit 0=势力1, bit 1=势力2, …） |
| 比较符 | 0002=等于 |
| 触发状态 | 0000=未触发, 0001=已触发 |
| 偏移量 | 单位 = 2 字节，相对 0x48 的指令流起始位置 |
| 嵌套层级 | IF/THEN/ELSE/END 的判断嵌套深度，从 1 开始 |
